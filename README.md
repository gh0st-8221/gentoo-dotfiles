# GhostWM Dotfiles

Awesome Gentoo Linux ghostwm helix rice, heavily styled with Catppuccin Mocha everywhere. To install, run:

```bash
git clone [https://github.com/gh0st-8221/ghostwm-dotfiles](https://github.com/gh0st-8221/ghostwm-dotfiles)
cd ghostwm-dotfiles
./install.sh
```

Package installation won't work on non-Gentoo distros, and systemd might fail if you use something cooler like OpenRC or runit.
